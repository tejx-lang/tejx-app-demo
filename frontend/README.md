# NomadOS React Frontend App (`frontend`)

The frontend application for **NomadOS | The Ultimate Digital Nomad Command Center & Super-App**.

## Features

- **25+ Real-Time API Widgets**:
  1. Current Weather (Open-Meteo)
  2. Air Quality Index (Open-Meteo AQI)
  3. IP Geolocation (ipapi / IP-API)
  4. Country Explorer (REST Countries)
  5. Currency Exchange & Converter (Frankfurter API)
  6. Public Holidays 2026 (Nager.Date)
  7. Stock Watchlist (Alpha Vantage / Finnhub)
  8. Live Crypto Tracker (CoinGecko / CoinCap)
  9. Global Tech News (HackerNews / Dev.to)
  10. Financial Sentiment Radar
  11. Free Dictionary Lookup (Free Dictionary API)
  12. World Time Zones (TimeAPI)
  13. Daily Activity Suggestions (Bored API)
  14. Dynamic QR Code Generator (QR Server)
  15. Email & Domain Validator
  16. Recipe Explorer (TheMealDB)
  17. Nomad Macro & Nutrition Calculator
  18. Daily Hotel Workout Planner
  19. NASA Astronomy Picture of the Day (APOD)
  20. Daily Motivational Quotes (ZenQuotes)
  21. Movie & Trending Shows (TVMaze)
  22. Video Game Releases (IGDB / OpenCritic)
  23. Pokémon Pokédex (PokeAPI)
  24. Anime Schedule & Tracker (Jikan)
  25. Pet Stress Relief (Dog.CEO API)
  26. **TejX Backend & MongoDB Hub**: Full CRUD for Users, Products, Orders, Notes, and Audit Logs!

- **Aesthetic Design**:
  - Deep space dark glassmorphic styling
  - Glowing accents and smooth responsive grid
  - Category filters, global search, and live clock

## Running Locally

```bash
# Development mode
npm run dev

# Production build
npm run build
```
